# 脾胃論 原文・現代語訳

金の李杲（東垣，1180〜1251）の『脾胃論』三巻の原文を，論と方ごとの小さな単位に分け，資料間の異同（校異）・校訂，日本語訳，解説を付けて，人にも機械にも読みやすい形にしたもの。

全105単位について，句読点を付けた原文，校異・校訂・注釈，日本語訳（原文の訳と解説）がそろっている。英訳はない。

## 構成

```
NN_巻/
  index.md      単位の一覧
  NNN.md        原文（句読点つき）＋校異・校訂・注釈
  NNN.ja.md     日本語訳：原文の訳・解説
images/         図
```

- 巻は 00（元好問の序と四庫全書の提要），01 巻上，02 巻中，03 巻下，04 後序（羅天益）。
- 単位は底本の見出し（論・方）ごとに1つで，巻ごとに 001 から番号を付けた。巻上12，巻中19，巻下71の単位がある。
- 長い単位は，段落の頭に〔§1〕〔§2〕…の番号を付けた。訳も同じ番号で対応する。
- 本文中の小注（方の各薬の分量や製法の注など）は，本文の中に（ ）で入れた。

### ファイルの頭の情報（YAML）

| キー | 内容 |
|---|---|
| book | 書名 |
| volume / volume_title | 巻の番号と巻名 |
| unit | 単位の番号（ファイル名） |
| title | 単位の題（底本の見出し） |
| punctuated | 原文に句読点を付けたか |

訳のファイル（`.ja.md`）の頭には `unit` `lang` `source`（対応する原文のファイル）を付け，方の単位には `formulas`（方の名）を付けている。

### 訳と解説の書き方

- 訳は直訳を基本とし，補った語は〔〕に入れた。
- 解説は1行目にその単位の要旨を書き，その後に要点を箇条書きにした。一般的な解釈を独自の言葉でまとめたもので，現代の注釈書からの引用はしていない。
- 底本の字が疑わしいところは〔底本は「X」〕と注記した。
- 文意の取りにくいところは，そのことを解説に書き，訳は字に沿った。推測で埋めていない。
- 引用の出典（『素問』『霊枢』の篇名など）で確かめきれないものは「と見られる」と書いた。
- 訳語と表記は，傷寒論・金匱要略などと同じ方針である。

## 他の古典との関係

『脾胃論』は，李杲が前著『内外傷弁惑論』に続いて著した書で，飲食・労倦によって脾胃が傷られると元気が不足し，「陰火」が盛んになって諸病が生じると論じる。『素問』『霊枢』の脾胃・胃気・昇降に関する文を多く引いて理論の拠りどころとし，『傷寒論』『金匱要略』の方（五苓散・建中湯・抵当湯など），銭乙の方（異功散・白朮散・瀉黄散など），『和剤局方』の方（平胃散・四君子湯・胃風湯など）を基にして加減する。

補中益気湯・清暑益気湯・升陽益胃湯・半夏白朮天麻湯・清胃散・葛花解酲湯など，後世に広く用いられた方の多くは本書にある。人参・麦門冬・五味子の組み合わせを「生脈」と呼ぶ箇所もあり，後の生脈散のもとになった。

各単位の解説の「他の古典との関係」に，その単位が先行の古典の何を引き，後世に何を残したかを書いた。

## 底本と，本文の補い・訂正

### 底本

- **どのような本か**：明の萬曆十一年（1583）の金陵周氏仁寿堂刊本。元好問の序，巻上・巻中・巻下，羅天益の後序がある。
- **どのように入手したか**：台湾の中醫笈成（jicheng.tw）が，この刊本（台湾國家圖書館所蔵）を底本として入力・公開している電子テキストを使った。句読点は中醫笈成のものによった。
- **字の変換**：中醫笈成のテキストは簡体字から繁体字に変換したと見られる字の誤り（「麺」と「面」，「穀」と「谷」，「鬱」と「郁」，「朮」と「術」など）を含む。四庫全書本の字と並べて，簡体字で同じ字になる組の字だけを直した（69か所）。電子テキストの誤りを直したもので，校訂には数えていない。その後，旧字・異体字を日本の新字体に直した（方針は `字体と変換の方針.md`）。

### 底本に足りないところ

- **四庫全書の提要**：底本にないので，四庫全書本から取って句読点を付け，序の巻に置いた。
- **図**：巻上の「臓気法時升降浮沈補瀉之図」は，京都大学附属図書館所蔵の和刻本『東垣十書』（[京都大学貴重資料デジタルアーカイブ](https://rmda.kulib.kyoto-u.ac.jp/item/RB00004306)）の画像から図の部分を切り抜いて載せた。底本とは版が異なる。巻中の「気運衰旺図説」は，この和刻本でも文字だけで，図はない。
- **巻下「清燥湯」**：底本は人参・白茯苓のところで薬の名が終わる。四庫全書本にある後半の7味と分量は，校異と訳の注に示した。本文は補っていない。

### 訂正（校訂）

- 本文を改めたのは7か所。明らかな誤刻で，四庫全書本・Wikisource・殆知閣の字で正せるものだけを改め，【校訂】として元の字句と根拠を記した。
- 『素問』『霊枢』などの引用の字句が今の本と違うところは改めず，校異に記した。

### 照合した資料

- **四庫全書本**：漢籍リポジトリ（Kanripo，KR3e0053）の文淵閣四庫全書本の電子テキスト。
- **Wikisource**（中文維基文庫）『脾胃論』（後序があり，明刊本の系統と見られる）と『脾胃論 (四庫全書本)』。
- **殆知閣**『脾胃论』。
- **校異**：これらの資料と底本の字句の違い。「X は「…」に作る」「…の間に，X は「…」がある」「X にない」の形で，どの資料かを示す。字体だけの違いと句読点は記していない。
- **四庫全書本の錯簡**：四庫全書本は，巻中の「涼血地黄湯」から「三焦元気衰旺」までの間で丁の順が乱れ，巻上の文の重出を含む。また巻下の「胃虚臓腑経絡皆無所受気而倶病論」の末に，巻上「君臣佐使法」の一節が重ねて入っている。照合では四庫全書本を底本の順に並べ直し，重出を除いた。このことはそれぞれの単位の【注釈】に記した。
